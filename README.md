# Border Eye — Monitoring Dashboard

A React and TypeScript monitoring dashboard developed as the frontend component of a collaborative defense-technology project presented at the World Defense Show.

## My contributions
- Independently developed the React/TypeScript dashboard and user interface.
- Created mock datasets to simulate monitoring outputs.
- Built views for dashboard monitoring, mines, vehicles, intruders, and settings.

## Project scope
The wider team worked on hardware, AI models, and other system components. **This repository contains only the frontend dashboard and simulated data.** It does not claim to implement live detection, real sensor integration, or operational defense capabilities.

## Tech stack
React, TypeScript, Vite, Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```

## Attribution
Collaborative team project. This repository showcases my frontend contribution; other project components were developed by teammates.

## Notes
The displayed data are simulated. Do not use this demo for real-world safety or operational decisions.
